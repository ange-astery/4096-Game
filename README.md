# 4096

**4096** is a C++ recreation of the classic **2048** tile-merging game. The name is a playful nod to the larger tile players can aim to create.

This project is being developed as a student project at **Polytech Dijon**.

## About the game

The goal in 2048 is to slide numbered tiles around a grid, combine matching tiles, and build toward the 2048 tile. A move shifts the tiles in one direction; matching tiles merge as they meet. Keep merging and try to reach the highest tile possible.
